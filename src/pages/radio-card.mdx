# Radio Card

A selectable option card group for single-choice selections such as style presets, plans, providers, or configuration modes.

## Import

```tsx
import { RadioCard, RadioCardGroup } from '@/dashkit/RadioCard'
```

## Installation

Add the radio card component to your project using the Dashkit CLI:

```bash
bunx carllosnc/dashkit add radio-card
```

## Style Preset Example

Use `RadioCardGroup` with `label` and `valueLabel` to display the group title and active selection summary above a stack of option cards.

<Preview>
  <PresetDemo />
</Preview>

```tsx

<RadioCardGroup
  label="Style Preset"
  valueLabel={preset}
```

## Radio Indicator & Sizes

Use `indicator="radio"` when you want a traditional radio circle inside each card, and `size` (`'sm' | 'md' | 'lg'`) to adjust density.

      <RadioCard value="eu-west" title="EU West (Ireland)" description="GDPR compliant European region" />
    </RadioCardGroup>
  </div>
</Preview>

## Accessibility

- Uses `role="radiogroup"` on `RadioCardGroup` and `role="radio"` with `aria-checked` on each `RadioCard`.
- Full keyboard navigation: `ArrowDown` / `ArrowRight` move to the next enabled card, `ArrowUp` / `ArrowLeft` move to the previous enabled card, and `Home` / `End` jump to the first or last enabled card.
- Pass `name` on `RadioCardGroup` to include a hidden `<input>` for native HTML form submissions.

## Props

### RadioCardGroup

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `value` | `string` | `-` | Controlled selected value. |
| `defaultValue` | `string` | `-` | Initial selected value for uncontrolled usage. |
| `onValueChange` | `(value: string) => void` | `-` | Callback fired when selection changes. |
| `name` | `string` | `-` | Optional form field name rendered as a hidden input. |
| `label` | `ReactNode` | `-` | Uppercase group label displayed at top-left. |
| `valueLabel` | `ReactNode` | `-` | Active selection summary displayed at top-right. |
| `columns` | `1 \| 2 \| 3 \| 4` | `1` | Responsive grid column count. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Card padding density inherited by children. |
| `indicator` | `'none' \| 'radio' \| 'check'` | `'none'` | Selection indicator style shown on each card. |
| `disabled` | `boolean` | `false` | Disables all cards in the group. |

### RadioCard

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `value` | `string` | Required | Unique option value within the group. |
| `title` | `ReactNode` | Required | Primary option heading. |
| `description` | `ReactNode` | `-` | Secondary supporting text below the title. |
| `leading` | `ReactNode` | `-` | Optional leading element (color dot, icon, avatar). |
| `trailing` | `ReactNode` | `-` | Optional trailing element (price, badge, shortcut). |
| `size` | `'sm' \| 'md' \| 'lg'` | Group `size` | Overrides the group size for this card. |
| `indicator` | `'none' \| 'radio' \| 'check'` | Group `indicator` | Overrides the group indicator for this card. |
| `disabled` | `boolean` | `false` | Disables this individual card. |
