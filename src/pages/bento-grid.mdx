# Bento Grid

A modular grid layout system for building regular and irregular Bento or Hairline grids while maintaining seamless `1px` shared border coherence across arbitrary column/row spans and responsive breakpoints.

## Installation

Add the BentoGrid component to your project using the Dashkit CLI:

```bash
bunx carllosnc/dashkit add bento-grid
```

## Import

```tsx
import { BentoGrid, BentoGridItem } from '@/dashkit/BentoGrid';
```

## Sharp Architectural Wireframe (`rounded="none"`)

Set `rounded="none"` for a sharp editorial or architectural blueprint layout where every outer corner and inner intersection meets at 90 degrees.

  <BentoGrid cols={{ base: 1, md: 12 }} rounded="none" autoRows="minmax(120px, auto)">

## Spaced Bento Cards

Pass `gap="sm" | "md" | "lg"` when you want detached Bento cards instead of shared hairline borders.

<div className="not-prose my-6">
  <BentoGrid cols={3} gap="md">
    <BentoGridItem colSpan={2}>
      <h4 className="text-sm font-semibold text-foreground">Detached Bento Card (2 cols)</h4>
      <p className="text-xs text-muted-foreground mt-1">Automatically switches to individual card borders when gap is enabled.</p>
    </BentoGridItem>
    <BentoGridItem colSpan={1} surface="muted">
      <h4 className="text-sm font-semibold text-foreground">Side Card (1 col)</h4>
      <p className="text-xs text-muted-foreground mt-1">Muted surface variant.</p>
    </BentoGridItem>
  </BentoGrid>
</div>

```tsx
<BentoGrid cols={3} gap="md">
  <BentoGridItem colSpan={2}>Detached Bento Card</BentoGridItem>
  <BentoGridItem colSpan={1} surface="muted">Side Card</BentoGridItem>
</BentoGrid>
```
