# Customization

> Architecture reference for AI agents and LLMs customizing Dashkit UI tokens, variants, and presets.

## AI Customization Protocol (3 Tiers)

Always prioritize edits in this order:

1. **Tier 1 — Global Theme (`src/dashkit/dashkit.css`)**: Global brand colors, neutral palettes, dark/OLED mode, border radius, and flat vs. gradient surfaces. Edit `:root` and `.dark` variables or apply `data-*` attributes.
2. **Tier 2 — Component Variants (`src/dashkit/[Component]/[Component].tsx`)**: App-wide component styling changes. Edit the `cva(...)` definition directly inside the component file.
3. **Tier 3 — Instance Overrides (`className` & `data-slot`)**: One-off layout tweaks on a single screen. Pass utility classes via `className`, or target internal slots via `data-slot` (e.g. `className="[&_[data-slot=label]]:uppercase"`).

## Architecture: Tailwind v4 `@theme inline`

Dashkit connects semantic utility classes to CSS custom properties via `@theme inline` in `src/dashkit/dashkit.css`:

```css
@theme inline {
  --color-background: var(--ds-bg);
  --color-foreground: var(--ds-fg);
  --color-card: var(--ds-card);
  --color-popover: var(--ds-popover);
  --color-border: var(--ds-border);
  --color-primary: var(--ds-primary);
  --color-primary-foreground: var(--ds-primary-fg);
  --color-input-bg: var(--ds-input-bg);
  --color-input-border: var(--ds-input-border);
  --color-input-focus: var(--ds-input-focus);
  --color-input-fg: var(--ds-input-fg);
}
```

## Token Reference

### Core Surfaces & Borders
- `--ds-bg`: Base canvas background (`bg-background`)
- `--ds-fg`: Main foreground text (`text-foreground`)
- `--ds-card`: Card and panel surface (`bg-card`)
- `--ds-card-fg`: Card text foreground (`text-card-foreground`)
- `--ds-popover`: Floating surfaces for dropdowns, tooltips, dialogs (`bg-popover`)
- `--ds-border`: Default border color (`border-border`)

### Interactive & Brand Actions
- `--ds-primary`: Primary action color (`bg-primary`, `text-primary`)
- `--ds-primary-fg`: Text on primary action (`text-primary-foreground`)
- `--ds-primary-gradient`: Linear gradient for filled buttons (`none` for flat style)
- `--ds-secondary`: Secondary action background (`bg-secondary`)
- `--ds-accent`: Subtle selection and hover highlight (`bg-accent`)

### Status & Feedback
- `--ds-danger` / `--ds-danger-fg`: Error and destructive actions (`text-danger`, `bg-danger`)
- `--ds-success` / `--ds-success-fg`: Confirmation and positive indicators (`text-success`)
- `--ds-warning` / `--ds-warning-fg`: Caution and warning alerts (`text-warning`)
- `--ds-info` / `--ds-info-fg`: Informational badges and icons (`text-info`)

### Form & Input Controls
- `--ds-input-bg`: Input field background (`bg-input-bg`)
- `--ds-input-border`: Unfocused input border (`border-input-border`)
- `--ds-input-focus`: Focused ring and border highlight (`focus:border-input-focus`)
- `--ds-input-fg`: Input value text color (`text-input-fg`)
- `--ds-input-ring`: Focus ring box-shadow color

### Geometry, Corner Radius & Tactile Shadows
All corner radii derive dynamically from `--radius`. Modifying `--radius` updates all components instantly without React changes:
- `--radius`: Master geometric scale (Default: `0.75rem`)
- `--radius-sm`: Derived as `max(0px, calc(var(--radius) - 5px))` (Checkboxes, small Badges)
- `--radius-md`: Derived as `max(0px, calc(var(--radius) - 3px))` (Inputs, Buttons)
- `--radius-lg`: Derived as `var(--radius)` (Cards, Popovers)
- `--radius-xl`: Derived as `calc(var(--radius) * 1.3333)` (Modals, Drawers)
- `--radius-2xl`: Derived as `calc(var(--radius) * 1.6667)` (Hero containers)
- `--ds-pill-radius`: Derived as `calc(var(--radius) * 9999)` (Pill Buttons, Switches, Chips, Sliders; set to `0rem` for square pills)
- `--ds-border-width`: Structural border thickness for surfaces and controls (Default: `1px`, `2px` in Brutalism)
- `--ds-card-shadow`: Surface elevation, hard offset, or glow shadow (Default: `none`)
- `--ds-button-shadow`: Tactile elevation on buttons (Default: `0 1px 2px 0 rgb(0 0 0 / 0.05)`)
- `--ds-button-border`: Border color for filled/soft buttons (Default: `transparent`, `var(--ds-border)` in Brutalism)

## Dynamic Runtime Attributes

Dashkit supports instant dynamic switching via HTML attributes without changing CSS files:

### Base Neutral Palette (`data-base`)
Applies neutral gray scales (`ds-0` through `ds-950`):
- Values: `zinc` (default), `slate`, `gray`, `neutral`, `stone`, `taupe`, `mauve`, `mist`, `olive`
- Scope: Set on `<html data-base="...">` or scoped on any container `<div data-base="...">`

### Primary Brand Color (`data-primary`)
Applies primary brand swatches (`ds-primary-50` through `ds-primary-950`):
- Values: `blue` (default), `violet`, `indigo`, `emerald`, `green`, `rose`, `orange`, `amber`, `cyan`, `teal`, `fuchsia`, `red`, `yellow`, `lime`, `sky`, `purple`, `pink`
- Scope: Set on `<html data-primary="...">` or scoped on any container `<div data-primary="...">`

### Dark & OLED Background (`data-dark-bg`)
- `data-dark-bg="oled"`: Forces `.dark` background `--ds-bg` to pure `#000000` black.

## Preset Delta Layer (`src/dashkit/presets/`)

Presets are token-override layers scoped to `[data-preset="<name>"]`:

- `src/dashkit/dashkit.css`: Base engine and default token values.
- `src/dashkit/presets/brutalist.css`: Neo-Brutalist preset (`--radius: 0rem`, `--ds-pill-radius: 0rem`, `--ds-border-width: 2px`, hard offset shadows).
- `src/dashkit/presets/matrix.css`: Cyber Terminal preset (`--radius: 0.125rem`, phosphor green palette, CRT glow shadows).
- `src/dashkit/presets/index.css`: Preset aggregator.
