# Sidebar

A versatile and premium navigation sidebar component that supports complex layouts, branding, status indicators, and responsive mobile drawer adaptation out of the box.

## Import

```tsx
import { 
  Sidebar,
  SidebarProvider,
  SidebarTrigger,
  SidebarContent,
  SidebarHeader, 
  SidebarHeaderOpen, 
  SidebarHeaderClose, 
  SidebarFooter, 
  SidebarFooterOpen, 
  SidebarFooterClose, 
  SidebarSection, 
  SidebarItem,
  SidebarSubList,
  SidebarSubItem,
  useSidebar
} from '@/dashkit/Sidebar/Sidebar'
```

## Installation

Add the sidebar into your project using the Dashkit CLI:

```bash
bunx carllosnc/dashkit add sidebar
```

## Basic Usage

The `Sidebar` uses a semantic composition of headers, content scroll area, sections, and footers to create a cohesive navigation experience.

<div className="not-prose">
<InteractiveSidebar />
</div>

```tsx
import { Sidebar, SidebarHeader, SidebarContent, SidebarSection, SidebarItem } from '@/dashkit';
import { FiLayout, FiActivity, FiSettings } from 'react-icons/fi';

export default function App() {
  const [activeTab, setActiveTab] = useState('dashboard');

  return (
    <Sidebar className="w-64 border-r">
      <SidebarHeader>
        <Logo />
        <span>Dashkit</span>
      </SidebarHeader>

      <SidebarContent>
        <SidebarSection title="General">
          <SidebarItem
            icon={<FiLayout />}
            active={activeTab === 'dashboard'}
            onClick={() => setActiveTab('dashboard')}
          >
            Overview
          </SidebarItem>
        </SidebarSection>
      </SidebarContent>
    </Sidebar>
  );
}
```

## Responsive Mobile Drawer

By default (`responsive={true}`), the `Sidebar` automatically adapts between desktop and mobile devices:
- **Desktop (≥ 768px)**: Sits in the layout flow and smoothly expands or collapses between `width` (272px) and `collapsedWidth` (72px).
- **Mobile (< 768px)**: Disappears from the layout flow so the main content takes full width, and opens as an accessible sliding **Drawer with Backdrop Blur** via `<SidebarTrigger />`.
- Supports focus management, `Escape` key to close, swipe gestures, and dynamic viewport heights (`100dvh`).

```tsx
import { SidebarProvider, Sidebar, SidebarTrigger, SidebarContent, SidebarHeader, SidebarSection, SidebarItem } from '@/dashkit';
import { Navbar, NavbarBrand } from '@/dashkit';

export default function DashboardLayout({ children }) {
  return (
    <SidebarProvider>
      <div className="flex h-screen w-full">
        {/* On desktop: in-flow collapsible sidebar. On mobile: portal Drawer */}
        <Sidebar>
          <SidebarHeader>My App</SidebarHeader>
          <SidebarContent>
            <SidebarSection title="Menu">
              <SidebarItem icon={<FiLayout />}>Dashboard</SidebarItem>
            </SidebarSection>
          </SidebarContent>
        </Sidebar>

        <div className="flex-1 flex flex-col min-w-0">
          <Navbar>
            <NavbarBrand>
              {/* Toggles sidebar on desktop or opens Drawer on mobile */}
              <SidebarTrigger />
              <span>Dashboard</span>
            </NavbarBrand>
          </Navbar>

          <main className="flex-1 p-6">
            {children}
          </main>
        </div>
      </div>
    </SidebarProvider>
  );
}
```

## Collapsible Sidebar

Enable the `collapsible` prop to show a floating toggle button on the desktop sidebar edge. You can use the `isOpen` state to conditionally render content using native utility components.

```tsx
<Sidebar collapsible defaultOpen={true}>
  <SidebarHeader>
    <SidebarHeaderOpen>Full Branding</SidebarHeaderOpen>
    <SidebarHeaderClose>Logo</SidebarHeaderClose>
  </SidebarHeader>
  {/* ... items ... */}
</Sidebar>
```

## Collapsible Sections

Sections can be individually collapsed to conserve vertical space or group related functionality. Use the `collapsible` prop on `SidebarSection` to enable this behavior. You can also control the initial expansion state with the `defaultOpen` prop.

  <CollapsibleSectionExample />
</Preview>

```tsx
<SidebarSection title="Account" collapsible>
  <SidebarItem icon={<FiUser />}>Profile</SidebarItem>
  <SidebarItem icon={<FiShield />}>Security</SidebarItem>
</SidebarSection>

<SidebarSection title="Settings" collapsible defaultOpen={false}>
  <SidebarItem icon={<FiSettings />}>Advanced</SidebarItem>
</SidebarSection>
```
